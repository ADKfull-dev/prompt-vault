# Prompt Vault

Landing page de vente de l'ebook « Prompt Vault » (116 prompts IA, PDF).

- Fichier unique : `index.html`
- Lien d'achat : modifier `CONFIG.checkoutUrl` en bas de `index.html` avec l'URL du produit Chariow.
- Avis clients : ajouter de vrais avis dans `REVIEWS` (la section reste cachée tant que la liste est vide).
