Connexion admin

L'espace admin enregistre les réglages directement dans le dépôt GitHub du site. Il faut un token GitHub avec accès en écriture au dépôt.

Créez un token « fine-grained » limité à ce dépôt, avec la permission Contents : Read and write. Le token reste dans cet onglet et disparaît à sa fermeture ; il n'est jamais enregistré dans le site.
